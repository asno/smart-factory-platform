# Smart Factory Edge Monitoring Platform

Industrial Edge/IIoT simulation platform using:

- Golang
- MQTT
- Sparkplug B
- Modbus TCP
- InfluxDB
- Grafana
- Docker

## Objectives

- Simulate industrial equipment
- Build OT/IT architecture
- Implement edge gateway
- Industrial telemetry
- SCADA supervision
- KPI/MES dashboards
